# P3 内部任职资格首轮交付

日期：2026-09-07

资格标准按编码建立不可变版本，定义适用规则并关联1–20项能力标准版本与1–5级要求。同一能力不混用多个版本。草稿仅HR/管理员可见，发布后开放申请，停用阻止新申请但不抹去既有申请。

员工本人或管理范围HR发起申请，非申请提交人且非本人受益的管理者独立评审。必须已有全部同版本达标的能力评估才能通过，未评定不视为0分或默认达标。认证保存标准与评估证据快照、内部唯一编号、有效期（可选）及评审人；后续能力重评不覆盖既有证据。撤回、拒绝和撤销留存过程记录。岗位及职级由原有人事审批办理，不由认证自动修改。

本轮新增两项API集成场景，覆盖版本不匹配、未评定阻断、本人/代办自审拒绝、认证证据冻结、有效认证防重复、停用与跨组织隔离。P3 19项及P2 21项累计40项通过。

尚不包含评委会多人评审、申诉、多序列类别模型、外部执业证书验证、有效期通知或资格与薪酬自动绑定。当前为企业内部认证记录。
