# P3 绩效首轮闭环验收

日期：2026-09-07。

已实现：组织范围内绩效周期、固定评分阈值与评级名称、启动/结束；员工目标及衡量标准、整数权重合计100%；经理/HR独立确认目标；员工自评；管理评价及加权总分；退回重提；HR发布；结果快照及人才盘点引用；计划取消、未完成计划阻止周期结项。

权限控制沿用企业成员和组织范围。不能确认、评价或发布本人绩效；发布前员工只能看自己的目标、自评和流程状态，不能通过列表或历史接口读取暂定评分和管理意见。已发布结果对本人开放，历史外部导入源记录仍不自动向本人开放。

周期阈值和评级由HR明确配置，例示值不是用户企业的已确认制度。计算为各目标百分制得分乘权重后求和，最终保留两位小数；按固定阈值映射低/中/高档。发布保存周期规则、目标、评价与发布依据快照；可明确替代同员工、同期间的最新历史源记录，防止无提示覆盖。

新增一项实际API集成场景：周期权限→目标权重→本人操作限制→目标确认→自评→加权评价82分→暂定结果隐藏→HR发布优秀/高档→防重复发布和发布后退回→盘点引用→周期结束→员工读取已发布结果。与人才学习7项、既有21项共同形成29项自动化场景基线。类型检查、标准构建是保存发布门槛。

边界：目前为目标评价与结果发布主流程，尚未覆盖完整OKR、组织绩效、强制分布、多级结果审批、绩效申诉和已发布结果更正流程。原站绩效详细规则尚未逐项核验。不会通过“历史导入更正”绕过已发布结果的保护；正式生产使用前需完成企业绩效制度与结果更正规则验收。未进行真实员工数据或真人多账号试运行。
