# 总工作量一级估算 E1（排期参考）

日期：2026-09-07。工程粗估：对外取整为 **10%–20%**，中值约 **15%**（原始加权结果9.9%–18.8%，仅供复算）。不是生产验收率，不是工时核算，不是统计置信区间。

## 为什么现在可以给出区间

此前没有共同分母，旧35%等数字已撤回。E1首次把已观察的48组菜单与P1/P2/P4/P5横向工作放在一份可审阅的估算表中。仍未完成逐条需求验证，因此仅允许粗估区间，不能写成精确已完成率或承诺。若新增范围、企业制度或集成约束显著改变工作量，须说明原因并发布E2，不能暗改分母。

## 估算假设

- 假定目标继续覆盖当前48组菜单所代表的能力，含生产所需工程与验收工作；未把不可见子功能自动认定为已确认范围。
- 权重是根据当前菜单描述、数据敏感性、业务分支、跨模块及外部集成复杂度给出的相对工程判断，不是来源系统数据或实际工时。高权重如薪酬/学习，低权重如单一填报/配置；未开发AI和外部服务也留在分母中。
- P3权重计领域专属分析、实现及模块验证；P1计全量盘点/范围与证据管理，P2计共享基础，P4计跨模块及企业验收，P5计运行、迁移与切换，避免重复计同一基础实现。
- 每个包上下限为完成工作量的粗估占比，仅依现有代码、验收文档及明确缺项判断。没有独立实现的包记0；共享问卷/人才基础不在其他菜单重复领取完成额度。
- 区间尚未纳入全部权重误差，实际不确定性可能更大。它只用于回答大致剩余规模；生产验收仍为未完成。

公式：总估算上下限 = Σ（包权重 × 包完成上下限）÷ Σ包权重。当前分母 **1704相对点**。相对点不能直接转换为日历或人日。
