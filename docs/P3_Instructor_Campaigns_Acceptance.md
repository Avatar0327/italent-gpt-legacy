# P3 认证报名与入册关联

2026-09-07，独立实现，原站结构及一项活动配置见P1观察记录。开发完成，新增3项合成API集成场景通过；生产验收未完成。

| 业务段 | 已实现与验证 | 尚未包含 |
|---|---|---|
| 活动 | 组织含下级、等级、授课领域、资格条件、日期窗口；草稿发布和停止报名 | 编辑版本、活动模板、精确到分钟的报名窗口 |
| 报名 | 本人申请、日期和组织检查、在途重复阻止、未关联时撤回 | 批量安排、外部讲师、导师 |
| 资格 | 非本人HR独立复核、下级HR处理本部门报名 | 任意多级配置审批 |
| 提名 | 创建真实关联提名，使用服务端固定等级和领域；一个报名只关联一个提名 | 自动任职或课程认证 |
| 试讲入册 | 活动提名强制完成最新试讲，通过后独立核对入册 | 活动培养编排、证书、课酬 |
| 权限和事务 | 上级活动下级只读，不能停止上级活动；原子审计失败回滚 | 企业多角色UAT、容量与恢复演练 |

报名资格条件与授课领域使用不同字段；不能把资格材料当作已经认证的授课能力。通过资格不等于入册，入册不等于课程版本认证。所有新操作只涉及本系统合成数据。
