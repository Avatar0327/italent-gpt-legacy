# P3 内部讲师试讲子流程

2026-09-07。需求参考一个原站活动的100分等权平均配置；其余约束明确属于独立实现，未通过企业生产验收。

- 对待复核内部讲师提名安排试讲；HR登记评价标准、通过分数、北京时间截止日和2–10名在职评委。每位评委必须已关联有效登录账号。安排后不更换名单或标准。
- 本人不得评价自己的试讲，评委只看本人的原始评分；HR评委也不例外。评委截止日前、冻结前可改本人评分，事件历史完整保留，仅非参评有权限HR可读原始历史。
- 全部评委评分齐备后，非安排人、非评委、非本人HR冻结均分。显示均分保留两位，是否通过直接比较原始整数总分与阈值乘人数，不用四舍五入结果决定通过。
- 活跃试讲阻止提名直接复核/撤回。安排过试讲的提名必须引用最新冻结通过结果；取消或失败须重试，旧分数和版本保留。未安排试讲的历史独立提名规则保持可用。
- 已冻结记录不可改分或取消；入册仍由HR独立核对，不自动授予课程认证、学分、课酬或更改任职。
- API修订号、会员校验和审计事务沿用既有基础。评分/冻结纳入待办；逾期未评分不显示可办理评分待办，HR可以取消后重排。

新增2项API集成场景通过。仍待完整活动报名及培养编排、导师流程、证书、企业评分制度验收、真实UAT与容量验证。
