# P3 干部人才档案与待办

来源边界：当前为已实现业务的独立汇总视图，原站完整干部档案细则未核实。

## 行为

- 管理员、HR、经理按当前组织范围查阅。员工、审批专用及薪酬专用角色不能访问本档案接口。
- 选拔任用、考察述职、资格、后备、人才盘点、核定绩效、发展行动、学习任务分别展示，保留来源模块入口；来源模块继续办理和保存审计。
- 最新盘点仅采用已发布且未被替代的版本；绩效包括正式已发布结果及历史核定录入的最新版本，区分来源。不读取未发布绩效计划，不合成排名。
- 资格有效期按北京时间日期判定，到期只是展示状态，不改写证书或原业务。缺失保留为空，不认定为不合格。
- 干部提名待办仅独立管理员/经理；考察核验待办为非发起人、非本人且同时具备员工与岗位范围的管理者。处理后消退。
