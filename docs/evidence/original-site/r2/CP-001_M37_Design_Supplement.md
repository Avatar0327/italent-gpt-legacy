# CP-001 M37字段映射设计补充建议

状态：建议待R2 P2设计负责人接受。维持dc6dd896固定设计及077e0dc独立通过，不直接修改P2分支、Schema或产品代码。

## 具体缺口与建议

原站四子集分别有独立行；subsetName不能同时表达集合名称与逐行关键点。建议保留已有IndicatorChild的稳定ID/父引用/顺序/description，补充按类型区分的字段映射，不将等级alias修复重开。

|原站行类型|已见原站字段|建议产品字段|约束|
|---|---|---|---|
|等级|等级名称/说明及已批alias、elementText|沿已批准等级结构|本提案不改既有等级契约|
|行为|行为关键点、行为描述|behaviorKeyPoint、description|关键点独立保存，不能用子集总标题覆盖|
|面试|面试关键点、面试问题|interviewKeyPoint、description|面试关键点及问题一对一回读；按现有面试权限投影|
|发展建议|建议类型、建议描述|suggestionTypeRef、description|保留原站原始类型文字及源字典版本；稳定type映射由设计负责人确认|

五种建议类型以captures/M37-four-subsets.json及原实测为依据，不能凭显示顺序生成稳定类型ID。未知类型保留rawLabel及unmapped状态，不能静默并入其它。

subsetName仅承载子集层级名称；上述是建议命名而非已经批准的最终Schema。若设计负责人确认现有字段足以无损承载，也须给出明确单射映射和反向还原示例。

## 受影响交付和验收

M37_Design.md、Interface_Schemas.json的IndicatorChild、源adapter、P3-R2-M37-01、M37-REVIEW-AC02/08需一致。至少验证：同子集两行不同关键点不合并；关键点与子集名不同仍可双向还原；建议类型未知不丢失；发布前后原子行版本不漂移；字段无权不投影。

CP-002已经获所有者批准，但只解决编码适配策略，不自动批准此处字段结构。编码映射须带源命名空间和唯一性检测，原始值与目标值建立可逆注册表，禁止单靠连字符替换实现通用逆映射（原下划线和连字符可能碰撞）。

独立评审范围：只复核此增量映射及相关严格Schema/adapter/AC，不撤销或重做整份R2 P2。
