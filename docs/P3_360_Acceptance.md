# P3 360度评估首轮交付

日期：2026-09-07

使用已发布的纯量表模板，项目保存题目快照；配置被评人、评估人及关系。发布前可移除错误邀请，发布后名单锁定。评估人必须为有效员工，只有本人可填报/修改；停止收集后全部答卷锁定。

HR为每名被评人单独发布一次不可变汇总报告。本人/上级分组可单独展示；同级/下级分组至少达到项目设置的3–10份有效回答才显示均分，不足时返回null。没有跨组总分和原始答卷ID，可避免利用总分或重复发布直接反推低样本组。该机制不承诺任何情形下的绝对匿名；项目HR和管理员保留实名审计权限，页面明示。

原始答卷仅项目HR、管理员及答卷本人访问。被评人仅有本人已发布分组报告，不开放评估名单或他人答卷。经理不默认继承下属360报告权限。邀请进入个人工作台待办。

实际API验证两个被评人的同级组：2份回答时隐藏分数，3份回答时正确得到均分3；验证本人填写、名单保密、草稿隔离、停止后拒绝修改、重复报告拒绝及被评人无法读取原始答卷。P3 23项，与P2共44项。

尚无多人自选评估人审批、权重总分、常模、报告PDF、自由文本、提醒或对HR不可追溯的匿名存储。正式评估关系、量表和反馈解释仍由企业确认配置。
