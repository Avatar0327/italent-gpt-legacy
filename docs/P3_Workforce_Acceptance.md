# P3 编制与合同首轮交付

日期：2026-09-07

## 编制

按岗位、起止日、整数人数建立草稿，经非申请人的管理者批准生效。同岗位有效期间不能重叠；修订仅能替代同岗位同期间的最新批准版本。新版本批准前旧版本继续生效。直接建档、异动终审、招聘入职共享容量校验，写入与审计保持同一版本事务。受控组织的新进员工须关联岗位；既有未关联档案不自动补配。

现有人数为当前非离职且关联该岗位的人数，不代表历史或未来预测；已超编不删除人员，阻止新增。尚不包含按法人/职级/FTE预算、待入职预占及借调。

## 合同

记录合同编号、主体、类型、日期、来源和签署证明。编号不复用；同员工同主体已签期间不得重叠。续签链接前一合同，原始记录不覆盖。HR或管理员独立核实终止事项，合同变更不修改员工任职状态。到期提醒为站内30天查询，不发送通知。附件沿用员工档案，尚未逐合同绑定。

员工只能查看本人已签署/已终止摘要；经理没有下属合同权限，草稿及办理依据仅HR/管理员读取。界面与业务登记不构成电子签或法律效力核验。

## 验证

新增实际API场景验证编制自审拒绝、未关联/超编新增阻断、招聘入职容量约束、修订独立生效，以及合同草稿保密、未来签署拒绝、重叠拒绝、续签、独立终止及不修改人员状态。P2 21项及P3 17项通过；共38项。
