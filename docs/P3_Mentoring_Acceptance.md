# P3 培训关系带教

2026-09-07，合成数据；独立设计，参照原站导师/师徒页面结构。尚未生产验收。

- HR登记培训导师，登记不等于已完成导师认证。
- HR对师徒双方有范围权限且非当事人，才能建立培训关系；双方在职、有员工关联账号，不得同人或期间重复。
- 导师本人记录、学员本人确认；导师可修改尚未确认或退回的记录，确认后锁定。
- 至少一项确认且无待处理记录才能申请出师；非安排人、非当事HR独立核对，未通过可退回。
- 终止不等于出师；未确认记录保留未确认状态，界面和待办按终止关系处理。停用导师前必须结束所有在途关系。
- 导师不获得学员通用人事档案权限，经理也不因经理角色直接读取非本人带教。组织关系同步、自动派课、报酬和证书未实现。
