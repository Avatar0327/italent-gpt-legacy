# P3 内部学习证书

2026-09-07，合成数据；已开发并通过新增2项证书集成场景和出师发证联调。生产未验收。

- 模板编码按组织固定，创建新版本保留原内容；仅当前已发布版本能新发放，停用新版不恢复旧版。
- 发放依据：同员工已独立核验完成学习、在用讲师入册、正式出师。HR本人及发放申请人不能独立发放或撤销。
- 编号全租户唯一且不能复用；同系列同依据不重复发待审或已发证书。
- 发放日按北京时间；有效天数含首日；长期有效不填写到期日。旧证书固定内容、来源摘要和有效期。
- 来源状态变化提示HR核对，撤销留痕；不自动修改旧证书。本人仅看展示信息及撤销原因，内部发放依据在通用接口和历史接口中同样遮蔽。
