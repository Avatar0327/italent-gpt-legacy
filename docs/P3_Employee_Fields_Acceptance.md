# 员工自定义字段首轮验收

更新：2026-09-07

## 已实现

HR或管理员可建立文本、数字、日期和单选字段，说明用途，分别设置员工可见、经理可见和员工可申请修改。默认仅HR管理。定义创建后固定，不允许改类型或放宽既有字段策略；停用后保留值和历史，编码不重用。

HR在组织权限内登记其他员工正式值。员工只可为本人已授权字段提交变更，待复核值不影响正式值。另一位HR复核通过后写入正式值；退回或撤回保留原值。本人即使具有HR或管理员角色也不能直接登记或复核自己的字段。字段停用后不能提交或通过申请，但可退回未结申请。

经理可见范围取字段授权与员工组织权限交集，只返回正式值；不返回申请内容，也不能访问变更历史。员工只能读取本人开放字段及历史。HR可查管理范围内历史，写入采用全局版本和原子审计。

## 验证

接口测试覆盖未授权字段及历史拒绝、跨组织写入拒绝、选项值校验、非法日期、待复核不改正式值、经理响应投影、本人HR自审拒绝、独立复核、旧版本冲突、重复处理、停用后拒绝生效及编码不重用。

## 范围

字段不替代核心岗位、职级、邮箱或薪酬数据，不影响既有核心字段权限。当前为单字段、单员工维护；尚未包含字段分组、条件必填、公式、批量导入、字段专属附件。真实字段清单由企业后续配置。未导入真实员工数据，也不能据本轮测试认定完整生产验收。
