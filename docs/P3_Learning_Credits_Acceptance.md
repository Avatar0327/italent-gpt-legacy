# 学习学分首轮验收

课程版本可配置一次固定学分规则，精确到0.01学分。规则不能覆盖修改；学分变化使用新课程版本。HR明确登记已核验完成学习对应学分，不自动回填历史。

同学习记录仅授予一次。撤销由非授予人、非受益人的其他授权HR办理，保留原授予记录并追加撤销台账。汇总为授予减撤销；课程规则及学习完成状态保持不变。

员工只见本人记录，管理人员按组织范围访问。未发布课程规则不向员工开放。接口验证覆盖版本固定、草稿规则及历史保密、成果核验前置、越权拒绝、重复授予、独立撤销、重复撤销、汇总及旧版本冲突。

首轮不包括学分到期、跨课程抵扣、学分等级、撤销后再授予、自动批量授予或企业学分达标制度。企业实际课程规则由授权人员按确认的制度配置。
