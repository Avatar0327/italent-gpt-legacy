# P3 内部讲师名册验收记录

2026-09-07；独立业务设计，合成数据。已开发并通过API集成测试，尚未生产验收。

- HR按核实依据登记内部讲师等级和授课领域，其他HR独立复核入册。提名人和讲师本人不得自审。
- 同员工只允许一个在途或在用记录。拒绝、撤回或停用后重提产生新版本并关联上个版本，不覆盖旧记录。
- 当前组织范围即时生效。离职员工不可提名或通过；在用后离职保留历史，经理目录不再展示，由HR停用。
- 经理只看范围内在职在用讲师摘要；本人可看自己各状态摘要；依据、复核意见及事件历史仅有权限HR可读。全量开发接口同样执行投影和历史权限。
- 独立复核接入学习待办，办理后消退。所有写入复用修订号与原子审计。
- 停用不自动撤销课程认证、不取消场次、不修改薪酬。外部讲师、导师、认证活动与试讲评审未实现。

验证：tests/p3-api.test.mjs 末两项新增场景通过；累计44项P3通过。涵盖角色/组织/本人隔离、重复申请、版本链、过期修订号、离职和审计失败回滚。真实多角色UAT、完整UI、负载及企业制度验收未执行。
