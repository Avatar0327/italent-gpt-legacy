# P3 假勤首轮交付与验收记录

日期：2026-09-07

## 已实现

- 管理范围内排班及取消；拒绝时间重叠与同一业务日期重复排班。
- 员工本人打卡，使用服务端时间，防止重复及下班早于上班。
- 补卡留存原始记录，经独立管理者核验后参与出勤统计。
- 假期类型、带薪标记、是否校验余额；以分钟为单位的有来源调整流水。
- 请假待批占用余额，批准转为已用，撤回与取消释放；排除休息时段。
- 出勤核验列示计划、请假、打卡及未覆盖时间，不自动生成扣薪。
- 采用共享权限、版本冲突保护、事务和不可变过程记录。

## 验证

类型检查及 P3 11 项集成测试通过。新增两项实际 API 测试覆盖余额占用/释放、重复审批、跨组织访问、补卡不篡改原始打卡，以及本人打卡、客户端伪造时间、先后顺序与重复打卡。既有 P2 21 项已于上一轮通过。未执行多人浏览器或生产验收。

## 待完善及生产输入

当前页面统一北京时间；每员工每业务日期一个班次、一次休息。尚不包含弹性/综合工时、轮班模板、设备与定位、加班、跨班请假拆分、自动年假授予、结转过期和考勤封账。企业工时与假勤制度须确认后配置，不能把未覆盖时段直接视为旷工。生产运行前仍需容量、备份恢复、真实角色和业务验收。
