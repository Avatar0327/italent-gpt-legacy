# P3 字段分组、完整性与待办

## 范围与来源

原站已观察到组织员工及公共字段设置菜单，具体字段设置业务页面尚未成功进入。本轮为独立实现的规则，不宣称与原站配置引擎一致。

字段分组、必填规则随定义创建后固定。旧字段默认“基本资料/选填”，不追溯强制修改旧数据。支持选填、在职必填、试用期必填、正式员工必填。停用或离职状态不纳入当前必填统计。

## 规则

1. 有权限HR登记正式值；本人申请由其他HR复核，继续使用原有权限与审计事务。
2. 符合当前必填条件时不能登记或申请清空；审批时重新按当前员工状态检查。拒绝申请保留原正式值。
3. 缺失检查只统计当前查看者可见定义及该员工正式值；数值0有效，待复核内容不计完成。搜索/分组不会改变汇总分母。
4. 未填写必填字段会提示缺失，不自动修改档案，也不作为未经企业确认的全系统转正/入职拦截条件。
5. 待办排除本人、提交人、非HR及范围外员工。摘要只含事项和姓名，不含字段值及依据；停用后仍可退回，办理后消退。
