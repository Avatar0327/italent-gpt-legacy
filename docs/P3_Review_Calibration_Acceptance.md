# 人才盘点潜力校准验收

2026-09-07

流程：最新已发布盘点 → 提交潜力调整及事实依据 → 独立管理者复核/驳回 → 其他HR发布新盘点。待复核可由提交人撤回；原记录不可覆盖。

校准仅调整潜力，允许改为未评定；不修改原绩效、原项目及人员任职。已结束项目可留下事后更正，不自动重开。人才池和继任记录当前为独立业务，不自动变更。
