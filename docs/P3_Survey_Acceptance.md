# P3 实名员工问卷交付

日期：2026-09-07

模板版本包含最多20道必答量表或单选题；发布后不可改题，项目固定模板内容及发布时在职员工名单。后续入职者不自动纳入。员工只能提交本人的答案，开放期间可修改或撤回，结项后锁定。HR不能代填。

明确实名收集；项目所属组织的HR及管理员可以查看姓名、答案和汇总，不提供匿名承诺。经理只有本人答卷权限；填报名单不下发给普通员工，包括项目历史快照。答卷修改与撤回留存历史，汇总只计算最新有效提交；没有数据的均分为空。员工工作台显示开放期内尚未提交的问卷任务。

P3新增实际API测试覆盖草稿、版本快照、发布名单冻结、非名单拒绝、伪造答案拒绝、修改不重复计数、撤回、零样本、结项锁定和经理隔离；20项通过。与P2累计41项。

不含匿名机制、360评估、自由文本/附件、分支逻辑、外部问卷链接、邮件提醒或群体对比。HR权限以问卷项目组织归属为准，人员后续调动不改变项目收集责任。所有题目内容和统计仅用于实际配置的收集目的。
