# P3 可见范围继任覆盖

报表依据当前启用岗位、在职员工和活跃后备记录计算。管理员、HR及经理有查询权限，数据仍须同时满足员工和岗位的当前范围。员工、审批及薪酬专用角色无此报表查询与导出权限。

计数按岗位内唯一员工计算，提供有效后备总人数及当前三档准备度人数。离职与关闭记录不计入，源记录保留。现任人数仅使用员工正式positionId。零值仅表示当前可见范围内不存在相应记录，不推定企业不存在人选，也不输出缺失人员身份。

分页、导出上限、CSV公式防护及导出审计沿用统一报表接口。测试覆盖跨组织部分可见、角色拒绝、关闭及经正式审批离职后的计数变化。

原站已核实继任列表列名和筛选入口；准备度选项、期间规则、地图和组织继任尚待核实，本报表明确为独立实现。生产与人工UAT尚未完成。
