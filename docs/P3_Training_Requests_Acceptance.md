# P3 内部课程培训申请

原站已核实培训申请管理列表、筛选及“安排学习任务”入口。审批链和自动派课规则未核实，本轮为独立首轮实现。

## 流程和边界

1. 当前在职、已关联档案的员工申请已发布内部课程版本并说明需求。同课程版本只允许一项在途申请；已有学习记录时引导使用原记录。
2. 当前组织范围内其他管理员、HR或经理独立批准/拒绝。本人或提交人不得自审。批准时重新检查员工在职与课程发布状态。
3. HR先在学习中心按现有能力安排学习任务，然后关联批准后创建、同员工同课程版本且未取消的真实任务。关联保留批准及安排依据；经理不能替代HR办理核对。
4. 已批准但尚未核对的申请可由本人撤回；核对后不能再次办理或撤回。同任务仅关联一次，原任务状态不因核对变成完成。
5. 学习任务取消、成果核验等仍在学习中心办理，申请的安排记录保留为历史事实，不自动跟随改写。原有课程领取方式不变，此申请不是全部课程的访问控制门槛。
6. 员工自助显示申请和真实学习任务；工作台显示独立审批或HR安排核对待办。

## 验证

API集成场景覆盖自审与跨组织拒绝、重复申请、批准前或不同课程任务拒绝、关联唯一、撤回限制、审计失败事务回滚、本人自助与待办消退。测试使用合成数据，不改动原站。

尚未实现外部培训、费用采购报销、自动派课、培训项目申请、复杂审批规则及企业制度验收。
