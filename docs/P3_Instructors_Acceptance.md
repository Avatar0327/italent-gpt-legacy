# 内部讲师认证验收记录

日期：2026-09-07

## 实现范围

入口 `/instructors`：本人或组织范围内HR提交课程版本认证，记录试讲依据和有效期间，独立HR批准/拒绝。提交人撤回待审记录；其他有权限HR可撤销已批准认证。员工仅见本人，普通经理不读取他人认证依据和历史。

同员工、课程版本、重叠期间的待审/批准记录不得重复。过期、离职或停用课程不能获批。审批状态保持历史事实，页面按北京时间另示到期或未生效。

培训场次可选择认证：必须在职、已批准、课程版本相同且覆盖整个场次期间；讲师姓名从认证快照取值，不信任客户端传入。排期保存认证ID、员工ID、姓名和有效期间，不复制认证申请依据。相同讲师员工ID或姓名、相同场地的重叠排期被拒绝。

认证撤销不改写历史场次，也不取消学员出勤；禁止新增引用，现有活跃场次提示复核。手工填写讲师保留兼容并明确未引用认证。

## 验证

新增API集成场景通过：非法日期、重叠申请、本人/提交人不得复核、经理与审批人越权、历史隔离、重复审批、伪造姓名覆盖、排期冲突、跨日超期、新课程版本不可复用、撤销后拒绝新排期、快照保留、撤回和旧版本409。全套P3共29项通过。

## 原站证据与限制

原站认证、建设概况和设置菜单已观察；认证业务页面尚未进入，未将其字段和规则声明为已核实。当前为独立首轮实现，不含外聘讲师、等级制度、课酬结算、自动通知、自动取消既有场次。未将“所有课程必须使用认证讲师”假设为企业政策。
