# P3 干部提名与考察首轮交付

日期：2026-09-07

- 提名覆盖员工与目标岗位双重范围，可选关联当前有效资格认证及同岗位后备，并保存来源快照。禁止本人提名、自审和在途重复提名。
- 独立审议通过后仍需原有人事调动审批。任用核对只能引用提名批准后发起且已终审通过的匹配调动，核对时当前任职须一致；一个调动不能重复关联任用记录。
- 任用核对后建立考察目标与期限，员工本人提交述职；非发起人且非本人受益的管理者核验，支持退回补充。结果不自动修改人员状态。
- 选拔提名仅管理范围人员可见；普通员工可查看本人考察、提交述职并在个人工作台看到待办。

实际API场景验证自审拒绝、未完成调动不能任用、真实调动联动、重复核对拒绝、代述职拒绝、独立核验、退回补充、档案状态不变。P3 21项与P2 21项累计42项。

剩余：多级人委/董事会审议、集体会议、公示、完整干部档案、免职、任期与复杂考察延期机制。此处规则是独立系统的首轮流程，不代替企业正式授权制度。原站选拔任用入口尝试打开后新标签为空，未获得该页面完整字段/规则。
