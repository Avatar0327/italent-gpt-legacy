# P3 人才与学习：首轮闭环验收记录

日期：2026-09-07。适用范围：按已确认顺序提前开发的干部人才、学习模块之基础业务闭环。本文不代表48组菜单全部实现，也不代表真实业务投产验收。

## 1. 已实现的业务

| 能力 | 实现与控制 |
| --- | --- |
| 员工资料附件 | 单个10 MB；PDF、PNG/JPEG、文本、CSV、DOCX/XLSX；文件名、声明类型和主要二进制签名校验；通过受权下载接口访问。默认仅管理员/范围内HR可见，上传时可明确向员工本人开放。删除留存元数据及审计。 |
| 能力标准 | 五级行为锚点；相同编码新增版本，历史标准不覆盖。通用五级结构为独立设计，不声称等同原租户的测评量表。 |
| 岗位要求与差距 | 关联岗位、标准具体版本和目标等级；按同编码最新要求比较同版本最近评估。缺失或版本不一致为“未评定”，不会转换为0分。 |
| 能力评估 | 记录具体标准版本、评估日期、等级、事实依据；阻止未来日期及本人正式评价。 |
| 历史绩效登记 | 保存期间、原始评级、来源凭证、三档映射和映射依据；同员工/期间防重复；更正追加新记录并引用原记录，不覆盖原始数据。当前为逐条登记，批量文件导入尚未实现。 |
| 人才盘点 | 草稿可修订；发布后不可重写；使用绩效快照；更正绩效不改写已发布盘点。未评定的潜力或绩效不会进入九宫格，九宫格按期间查看。 |
| 继任计划 | 岗位候选、就绪度、依据及关闭原因；提名不直接改变任职、薪资或员工状态。正式任职仍走原有审批。 |
| 个人发展计划 | 目标标准、目标等级、行动、截止日；员工提交成果，其他有权管理人员核验或退回；关联学习未完成不得完成计划。 |
| 课程 | 编码版本、正文与完成要求、能力关联、草稿附件、发布和停用；已发布课程及附件不可修改，修改需新版本。 |
| 学习任务 | 范围内分配或本人领取；同员工、课程版本防重复；可关联同员工同能力版本的发展计划；成果提交、退回重提和核验。 |
| 课程考试 | 草稿课程可配置固定试卷、及格线及最多次数；最多20题，2–6个选项，单选。服务端评分，员工/经理响应及历史接口不返回正确答案；考试通过后方可提交学习成果。 |
| 全过程留痕 | 每次人才/学习变更保存独立完整版本快照、操作主体、时间及审计；历史接口按20条分页；当前行与历史、审计共用同一数据库事务。 |

## 2. 权限与一致性

- 新业务使用现有企业成员、组织范围及稳定身份，不生成第二套账号体系。组织员工数据与人才数据须处于同一企业修订版本，否则要求刷新。
- 管理员/HR维护标准、绩效源记录和课程；管理员/HR/经理在组织范围内维护人才业务。员工仅见本人评估、计划、学习及考试记录；盘点潜力、绩效源记录、继任名单不向普通员工返回。审批人身份本身不授予人才管理权限。
- 学习成果和发展验收禁止本人、提交人自核验；权限和版本在写入时再次核对。前端隐藏按钮不是访问控制的唯一措施。
- 主要实体引用使用同租户外键；结构化行为锚点、快照、证据和题目保存在类型校验后的JSON字段中。新建三张表：`hris_development_records`、`hris_development_events`、`hris_attachments`，非企业整体JSON聚合。
- 附件对象先写入私有对象存储，元数据、版本和审计再原子提交；失败时清理对象。删除先标记不可访问再移除对象；物理删除失败保留墓碑，需运维补清。
- 新迁移0006–0008仅追加表、索引及附件可见性字段，未修改已经部署的0000–0005。

## 3. 验证证据

- P2及岗位任职回归：21项规则和实际API集成场景。
- 新增6项实际API集成场景，运行全部迁移至SQLite，模拟D1批事务、平台身份和对象存储。
- 场景覆盖：标准版本；历史绩效防重复和更正；已发布盘点快照；组织越权及本人评价；员工/审批人保密边界；继任不修改任职；计划与学习闭环；退回、重提、重复核验；历史证据保留；过期版本冲突；审计故障整体回滚；附件大小/类型/默认保密、受权下载和删除；对象写入后的版本竞争与失败清理；考试答案在列表和历史接口的保护、服务端评分与提交门槛；能力评估版本不匹配时保持未评定。
- `npx tsc --noEmit`及标准Sites构建为保存发布前门槛。
- 自动化测试使用合成数据；不在原站写入，不把原站员工记录复制进开发数据库。尚未进行真人多账号浏览器验收。

## 5. 生产投用前尚未通过的门槛

当前私有版本供验证，尚未开通真实员工范围。正式上线仍需：企业成员与身份入口确认、正式标准与评级映射验收、真实多角色试运行、迁移对账、业务容量与服务器分页优化、备份/恢复与对象存储补清演练、部署区域和运维归属。当前人才列表在服务端完成权限裁剪后由前端分页，历史采用服务端分页；大规模企业性能尚未验证。

附件内容校验仅包含类型与基础签名，不是病毒扫描或Office文件结构完整性检测。正式附件接收策略和恶意文件检测应纳入运维验收。考试是培训知识测验，不代表专业资质认证。学习完成不自动推断人才潜力，也不自动提升能力等级。
