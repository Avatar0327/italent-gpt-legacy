# P3 线下培训场次与出勤

日期：2026-09-07

支持培训项目中的课程场次、讲师、场地、北京时间与必修标记；同名讲师或场地不能在重叠时间安排场次。员工仅能访问其有效报名的场次，管理人员须具备项目及员工范围权限。

场次结束后提交出席材料，或由HR登记出席/未出席；须由非提交人、非本人受益的管理者核验。未出席不满足必修要求。补充记录保留历史，课程已完成后不能再重写出勤，也不能在已有学员完成课程后追加新的必修场次。

必修场次的出席核验接入课程成果核验；场次未结项阻止培训项目结项。有核验出席记录的场次不能直接取消。出勤是材料核验，不提供现场定位、人脸识别或自动设备签到。

P3新增实际API测试覆盖冲突排期、未报名访问、必修门槛、未出席记录、补充出席证据、独立核验、完成后保护、场次和项目结项。P3 22项，加P2 21项累计43项。

仍不含容量与候补、讲师档案、签到码、学时精算、费用结算、外部日历或讲师通知。
