# 生产准入与剩余范围

更新：2026-09-07

## 状态

P2基础平台完成本阶段验证。P3已具备组织员工、人才学习、绩效、招聘入职、假勤、核定薪酬录入复核、自助及报表的首轮流程。不能据此认定完整北森复刻或企业生产验收完成。站点保持所有者私密访问，未导入真实人事数据。

## 必需业务输入及验收证据

| 输入 | 用途 | 验收证据 |
|---|---|---|
| 用工主体、国家/城市、计薪周期 | 定义真实租户与适用计算范围 | 经业务确认的配置清单 |
| 薪酬/社保/个税/假勤制度及脱敏核算样例 | 自动核算与差异比对 | 常规、入离职、调薪、跨月、补发等样例逐项一致 |
| 正式人员及角色映射 | 验证权限和独立复核 | 至少员工、经理、HR、薪酬编制/复核多人试运行 |
| 现有SSO、考勤、财务接口文档及测试环境 | 确定集成和主数据责任 | 身份注销、同步重试、幂等、对账验收 |
| 首批人数、峰值并发、数据保留、恢复目标 | 容量和运维设计 | 容量测试、备份与恢复演练记录 |

## 仍未完成的能力（不以首轮流程替代）

- 组织员工：编制、合同及完整自定义字段；复杂再入职、兼岗和法人变更口径。
- 干部人才：完整任职资格、选拔任用、考察述职、校准会、360、多维模型等。
- 学习：问卷、师资完整档案、线下班级、学分与认证、AI陪练等。
- 绩效：完整OKR、申诉更正、多级结果审批。
- 招聘：渠道、门户、简历解析、面试日历、电子签、AI面试及推荐运营。
- 假勤：工时制度、弹性与轮班、设备、加班、跨班请假、余额授予结转及封账。
- 薪酬：自动税社保、专用授权、补发冲销、工资异议、代发和支付。
- 报表集成：查询扩展性、报表设计器、历史快照、SSO、主数据同步、财务接口。
- 其他已观察菜单：文化激励、福利、佣金、预算成本、凭证、会议、项目人力、RPA等仍待逐页盘点。

## 发布与运行准入

现有自动化覆盖业务分支、跨组织权限、私密字段、事务、版本冲突及导出。生产仍需实际多用户验收、安全评审、密钥轮换与监控、恢复演练、容量及数据迁移核对。不得从自动化通过直接推定这些证据已具备。
