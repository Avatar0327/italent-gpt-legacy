# 绩效申诉与更正首轮验收

更新：2026-09-07

员工对本人最新正式结果发起申诉；同结果版本仅允许一个未撤回申诉。仅待审可撤回。周期已关闭也可办理申诉，原周期不重开。历史导入结果不适用此评分申诉流程。

独立HR复核，不得由申诉人、被评人、原评价人或原发布人办理。复核可维持原结果，或按原快照目标、权重和阈值计算更正结果。获准更正后由另一位有范围权限HR核对发布；获准尚未发布期间原正式结果继续有效。

发布生成新绩效记录，记录被替代版本和申诉来源。旧绩效、旧计划及已有盘点快照不变；新盘点拒绝旧版本，正式绩效报表只返回最新版本。重复发布被拒绝。申诉原始依据仅本人和范围内HR可见，经理不能从更正结果或历史接口取得申诉原文。

自动验证覆盖上述完整链路，含角色变更后原评价人仍不能复核、跨组织拒绝、旧版本申诉拒绝、目标数量、独立发布、申诉撤回与维持原结果。补充假勤申请自助展示回归，以及更正状态在员工自助中的展示。

当前未配置企业申诉时限、复议委员会、时限催办或外部通知。后续需业务确认真实制度，不能以当前测试代替企业验收。
