# 假勤原站只读证据与既有实现对照

## BC-A01 导航与工作台（2026-09-08）
复用既有会话，经唯一“考勤文员工作台”搜索入口进入假勤。应用与报表同名入口不能混为业务模块；首个同名搜索曾进入报表，随后使用唯一工作台入口纠正，没有重建登录会话。

可见业务范围：考勤文员工作台（日/月、昨天、近7天、当前期间）、考勤综合查询、档案；排班/排班组/调班；考勤记录/工时/外出/日报/月报；休假/加班/出差/公出/支援/居家办公；假期余额/调休明细/调休管理/调休结算记录；出勤/休假/月报明细及报表设计；打卡数据、设置、AI排班。仅导航，不触发业务、审批、消息或导出。

## BC-A02 期间配置入口

设置分期间及日历、考勤方案、档案、排班、打卡、统计、公共配置。期间列表包含名称、考勤组织、仅通过档案匹配、向下共享、当前期间与启用状态。界面提示历史一年查询/计算限制，仅记录为该租户页面提示，不复制为本系统数据保留政策，也不删除历史。

新建期间空表正在核实；月报处理流程尚未读取。组织共享及档案匹配不能映射为现有员工组织权限而冒称已完整支持。

BC-A03 期间新建空表：名称、年份、考勤组织、向下级共享、仅档案匹配、状态；按月周期/开始日期/期间开始日期；执行规则支持自动冻结、自动发布、自动封存。界面明确不开启即手动模式，在月报汇总中办理；自动执行示例为期间结束后第1天冻结。仅读取空表后取消，未开关或保存，未验证实际定时执行。

自动任务、多组织共享、完整日历与年度生成不在首批冻结实现中；保留后续，不据上述提示删除历史数据或开启自动结算。

BC-A04 月报汇总页：汇总/明细/考勤申诉；员工/考勤组织/部门/月/人员状态筛选；未生成月报、未审批完成流程提示；冻结、发布、确认、封存分别统计，工具栏计算/导入/冻结/封存/更多操作。未点击任何计算、冻结、发布或封存。观察到发布与冻结并非严格同一状态计数，不能据界面假设强制线性流程。
