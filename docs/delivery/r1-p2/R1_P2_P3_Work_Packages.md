## 逐生产者联调的关闭标准

M48七项按入口逐行保留producerId、contractVersion、实际实现提交、输入输出摘要、当前授权/版本失败回执。M32当前15模块来源各记录目录/数据可用状态和指标批准依据；21现有数据集另核固定行键和逐列字典。R2/R3尚未完成的生产者只能将对应联调标依赖未满足，不能标零缺陷通过；已完成的R1合成任务照常交付。完整P4业务验收必须逐项关闭这些联调依赖。

P4用例：P4-ARC-03, P4-M01-01, P4-M19-01, P4-M32-01, P4-M48-01, P4-REC-06。E2解除/真实外发/生产恢复各依既有授权边界办理，不由P3测试员自批。
