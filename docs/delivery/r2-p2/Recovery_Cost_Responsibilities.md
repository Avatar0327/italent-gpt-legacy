# R2恢复、成本及阶段责任

<a id="targets"></a>
## 不变目标与R1依赖

RPO≤60分钟、RTO≤240分钟、可恢复保留30天不变；D1–D7/E1/E2不变。沿R1已批准方案A：每日全量基线+15分钟完整事务行日志+不可变文件manifest，独立安全账本和密钥/发送fence。日志必须含全部业务行变化而不只是outbox，版本、回避决定、答卷桥接、报告披露账本、命令墓碑和审计同一恢复序列。Cloudflare R2对象存储与“Release R2”是不同概念。

R1固定设计对平台官方export/import、定时执行、独立密钥与安全控制域的实际可用性仍设验证闸门；本轮没有新平台验证，不把历史说明当现状证明。P3先核可用接口与模拟故障，P4在获批范围验证实际恢复性能。平台能力缺失时相关生产开放blocked_runtime，完整R2设计继续，不改成每天一次备份冒达1小时RPO。

<a id="recovery"></a>
## 恢复包、次序与计时

恢复点ready须同时满足：完整数据库事务序列及所有R2域版本、全部被引用对象字节/hash、schema/migration-map版本、所需解密/验证密钥、当前可核安全deny账本及恢复manifest签名。共同可恢复时刻取数据库与文件最近共同完整点；只有DB备份完成不能算RPO完成。保留至少31份日基线和30天增量，最后一个存续恢复点仍引用的字节/密钥不可删；热数据48小时只影响读取效率，不缩短保留。

状态incident_confirmed→isolated→source_verified→database_restored→objects_verified→authorization_reconciled→business_checked→owner_approved→opened。任何unknown停在隔离。先禁止写入和外发、提升recoveryEpoch/fence，核manifest签名及完整性，恢复D1和文件，再用平台当前身份∩独立安全账本∩业务权限投影校准；恢复业务库不得恢复旧grant。R2优先复核M26匿名/身份桥接、M18发布指针、M17成员/任期、M03实际生效凭证，以及全部附件墓碑和unknown命令。

恢复后已发布报告先重新核当前受众及披露账本，未能恢复完整披露历史则保持敏感报告禁用，不能重新从零计披露预算。证书当前有效性按恢复后真实时刻判断；过期不回到备份时的valid。人员退出/解绑屏障依据当前安全事实先拒绝；逐单业务取消和旧外部回执另对账，不能伪称恢复即全部取消或发送。

|RTO预算阶段|分钟|责任/产物|
|---|---:|---|
|确认与隔离|15|运维事故负责人；incident、写/外发fence|
|选点和校验|20|备份负责人；共同manifest|
|数据库恢复|60|数据库负责人；完整事务序列|
|对象恢复与摘要|60|存储负责人；对象manifest核对|
|授权和业务对账|30|安全+六域负责人；deny及关键不变量|
|所有者开放审批|25|事故授权所有者；明确批准记录|
|预留|30|运维；总计240，不在事后排除人工审批耗时|

15分钟周期+5分钟调度抖动+20分钟封存预算=40分钟；45分钟告警、55分钟升级、60分钟违反目标。RTO从事故确认开始至完整受控开放计时，若故障更早发现应保留发现时间同时报告；不得在演练报告任意晚选计时点。P3/P4需验证峰值文件/答卷量下上述预算，未验证不能标达标。

<a id="cost"></a>
## 增量成本模型和选择边界

只继承R1在2026-09-09留下的历史估算口径，不作2026-09-10现价声明。储存量近似`B = 31×DB_GB + 30×daily_DB_delta_GB + current_objects_GB + 30×daily_object_delta_GB`。R2增量为同公式中的各项增量，加密钥/审计/调度/导出请求/网络费用；共享基线不得再把整个R1存储收费重复加一次。真正容量及供应商账单未知，P4采集后核算。

为可复核的敏感度示例（纯合成、非真实人数或容量）：R2新增DB 1GiB、每天0.05GiB，当前附件10GiB、日增0.2GiB，则增量约48.5GiB；沿R1历史单存储0.015美元/GiB月近似0.73美元/月。另一个10倍量级样例485GiB约7.28美元/月。以上不含备份执行、独立控制域、运维工时、请求/出口等，不是全成本预算或采购授权；GB/GiB计费换算按P4供应商实际口径修正。

方案A优先沿已批准能力；方案B若仅用官方接口的受控执行器可等价实现，须核独立密钥、15分钟调度和240分钟恢复；方案C预热隔离副本存在新增持续成本，只有确认A/B无法达标且量化价差后提交所有者决定。本轮无证据迫使新增不可逆架构或成本决定，不自行启用B/C、不降目标。局部依赖记录在责任矩阵中，不能用尚未测得的数据宣称预算无差异。

<a id="responsibility"></a>
## 责任与关闭证据

P2提供方案、边界、公式及故障验收建议；P3共享平台负责人负责调度/备份/独立安全账本适配，模块实施与测试负责人用合成数据证明幂等、混合版本、低样本、撤权与恢复后资格过期；P4运维提供真实容量/耗时/费用及签名恢复包，安全负责人验最小权限/匿名，业务HR验跨角色与流程，所有者批准生产切换和开放。

未分配个人姓名不会由本窗口创建成员。E1仅表示历史界面证据非UAT，E2仍仅所有者访问；P4若需实际多角色验证，由总控在现有授权机制下安排，本窗口不增加访问者。外部供应商尚未配置可保留not_configured，但若上线业务强依赖则阻该业务生产开放，不能变成静默“已成功”。
