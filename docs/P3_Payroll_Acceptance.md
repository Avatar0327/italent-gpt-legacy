# P3 薪酬基础流程交付记录

日期：2026-09-07

## 已实现

- 人民币工资批次（组织、年月、制度依据），同组织同期间防重复。
- 每项金额为整数分；应发、个人扣款、企业承担分类；企业承担不扣减实发。项目名称不得重复，扣款不得超过应发。
- 同一员工同一期间不得在其他有效批次重复建单；离职人员可按所属组织办理末期工资。
- 草稿编制、提交、独立复核、退回重审、发布锁定。编制参与人、提交人、批次创建者及领取本批次工资人员不能审批。发布不执行资金支付。
- 每项金额留存核定来源，编制历史与金额变更不可变，使用全局版本与原子审计事务。
- 当前只有管理员维护薪酬。HR、经理不默认继承权限；任何角色仅可作为本人读取已发布工资条，管理员除外。员工不读取企业承担、来源、编制人及草稿历史。

## 验证

P3 的 13 项实际 API 集成测试通过；新增覆盖整数金额、余额计算、重复工资、角色/历史隔离、本人受益、编制审批分离、退回重审、发布锁定、过期版本及审计故障回滚。累计与前期 P2 21 项为 34 项。未完成多用户浏览器或真实业务验收。

## 待完善与生产输入

需要企业薪酬/考勤制度、适用国家与参保城市、工资项口径、个税与社保核定规则。当前仅录入已核定金额，不提供自动法规计算；尚无补发冲销、累计预扣、银行代发、签收争议、专用薪酬授权角色。批次采用单组织含下级范围、单员工每月一张工资条；数据权限与组织调动的历史口径需业务确认。
