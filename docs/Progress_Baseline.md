## 持续有效的执行约束

用户已授权原站只读盘点、项目代码文档修改、必要验证、提交和当前所有者私有发布，不重复请求对话式确认。原站不写入、不审批、不导出真实人员数据；测试采用合成数据。复用已授权浏览器会话，遵守平台强制访问控制。真实迁移、扩大访问范围及正式业务切换另行确认。

模块顺序：组织员工 → 干部人才 → 学习 → 绩效 → 招聘 → 假勤 → 薪酬 → 自助/报表/集成。各模块先核实已可访问的规则；不能验证的部分明确标注独立设计。局部资料缺失不阻断无依赖的工作。完成一个功能或部署不作为主动停止理由。
